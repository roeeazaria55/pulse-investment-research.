# התראות PULSE לאנדרואיד — הגדרה חד־פעמית

הקוד משתמש רק בפרסום החינמי של ntfy.sh, ללא הרשמה למסלול בתשלום,
שיחות טלפון, הודעות SMS או שירות מחייב. ערוץ חינמי אינו מבטיח פרטיות:
נשלח רק מידע ציבורי. אין לשלוח אחזקות, סכומים, תזות או הערות.

1. התקינו [ntfy לאנדרואיד](https://docs.ntfy.sh/subscribe/phone/) ואשרו הרשאת
   התראות. אם הטלפון מגביל פעילות ברקע, הגדירו ל־ntfy סוללה ללא הגבלה.
2. צרו נושא אקראי באורך 24–64 תווים, רק אותיות אנגליות, ספרות, `_` או `-`.
   אפשר להשתמש במחולל הנושאים בתיעוד ntfy. אל תשתמשו בשם חשבון או חברה.
   באפליקציית ntfy הירשמו לנושא הזה בשרת `https://ntfy.sh`.
3. פתחו [GitHub → Settings → Secrets and variables → Actions](https://github.com/roeeazaria55/pulse-investment-research./settings/secrets/actions).
   בחרו **New repository secret** ושמרו:
   - `NTFY_TOPIC`: שם הנושא בלבד, ללא כתובת URL.
   - `PULSE_NOTIFY_CONFIG`: ההגדרה הפרטית בדוגמה להלן, אחרי התאמת החברות.
   - `NTFY_TOKEN`: אופציונלי בלבד, אם כבר קיים טוקן חינמי מתאים. אין צורך
     לרכוש מסלול או להפעיל אפשרות בתשלום. אין להדביק פרטים אלה בצ׳אט.
4. פתחו [PULSE notification test](https://github.com/roeeazaria55/pulse-investment-research./actions/workflows/notify-test.yml),
   לחצו **Run workflow**, בחרו `main` ולחצו **Run workflow** פעם אחת.
5. סגרו את PULSE ונעלו את הטלפון. ודאו שההתראה מופיעה במסך הנעילה
   ושהקשה פותחת את PULSE בנתיב הכולל נקודה. **אישור משלוח מהשירות אינו
   הוכחת קבלה בטלפון**. בדיקה זו דורשת את בעל הטלפון ואינה ניתנת להדמיה כהצלחה.

דוגמה להגדרת Secret פרטית (זו דוגמה על חברה אחת, לא רשימת המעקב שלכם):

```json
{
  "enabled": true,
  "companyIds": ["candidate-nebius"],
  "types": ["daily", "high", "reminder", "results", "schedule-change"],
  "quietHours": {"start": 22, "end": 7},
  "urgentOverride": false,
  "reminderDays": [3, 1]
}
```

מזהי חברות אפשריים: `candidate-nebius`, `us-meta-nasdaq-a`,
`us-dlo-nasdaq-a`, `candidate-ftai`, `us-lmnd-nyse-common`,
`candidate-sandisk`, `candidate-iren`, `candidate-next-vision`,
`candidate-enlight`, `candidate-brainsway`, `candidate-gilat-telecom`.

לכיבוי הגדירו `enabled: false`; לבחירת סוגים ערכו `types`; לשינוי תזכורות
ערכו `reminderDays` (0–14 ימים). שעות שקטות הן שעות מלאות לפי
`Asia/Jerusalem`, כולל שעון קיץ. `start == end` מבטל שעות שקטות.
עקיפה מפורשת של שעות שקטות: `urgentOverride: true`, ורק לאירוע רשמי
בחשיבות גבוהה או פרסום תוצאות רשמי. אין עקיפה לתדריך או לתזכורת רגילה.

רשימת החברות וההעדפות ב־Secret נפרדות מהמעקב בדפדפן. Actions אינו יכול
לקרוא localStorage. שינוי המעקב באפליקציה אינו משנה התראות אוטומטיות.
אין מסך שמציג כאילו קיים סנכרון כזה. אין Secret בקוד הדפדפן או בפיד.

## אמינות ושליחה חוזרת

שליחה מתרחשת אחרי פרסום Pages ונעשית מהפלט הציבורי המדויק שפורסם.
המשימה נועלת שליחות במקביל. לפני פנייה לשירות היא שומרת כוונת שליחה
ב־Actions cache, עם מזהי HMAC אטומים: ללא ערוץ, טוקן, שמות חברות או הודעות.
אם שמירת הכוונה נכשלת לא נשלחת הודעה. נשלחת בקשת רשת אחת לכל כוונה;
אחרי timeout עמום אין ניסיון אוטומטי נוסף, כדי לא לייצר כפילויות. גם
`sequence_id` יציב נשלח ל־ntfy. אין כאן הבטחת exactly-once או מסירה מובטחת:
קריסה בין שמירה למשלוח עלולה לאבד הודעה. אובדן/פינוי cache מאתחל בסיס
חדש ומדכא היסטוריה; אין משלוח מחדש של ההיסטוריה באתחול.

הגבלה מקומית: לכל היותר 10 ניסיונות בריצה ו־40 ביום. החינם כפוף למגבלות
ntfy, חסימות קצב ורקע אנדרואיד; אין עקיפת מגבלות או הפעלה אוטומטית של תשלום.
קישור HTTPS פותח את הפריט בדפדפן או ב־PWA אם המכשיר משייך אותו; לא מובטח
שהמערכת תפתח דווקא חלון PWA עצמאי.

ריצה חוזרת של אותה בדיקת ניסיון לא שולחת שוב. לבדיקה נוספת התחילו ריצת
workflow חדשה. התזכורות מחושבות ב־09:00 ואילך לפי התאריך הרשמי ללא המצאת
שעת דוח. שינוי מועד מתריע רק אם נרשמה קודם כוונת תזכורת לאותו דוח.
זיהוי הודעה על מועד עתידי או שיחה אינו הודעה שהתוצאות פורסמו.
